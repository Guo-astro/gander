Une petite application qui ouvre à peu près n'importe quel fichier, entièrement sur votre téléphone.

Gander est une visionneuse hors ligne de documents pour Android. Ouvrez un PDF, un document Word, une feuille de calcul ou une photo : le fichier s'affiche aussitôt, sur l'appareil, sans compte, sans inscription et sans passer par le cloud.

Tous les formats qu'on vous envoie :

- Documents PDF, page par page, avec zoom par pincement
- Documents Word (.docx, et Word 97-2003 .doc)
- Textes OpenDocument (.odt) et Rich Text (.rtf)
- Feuilles de calcul Excel (.xlsx, .xls, .xlsm, .xlsb, .csv, .ods), avec des onglets pour les classeurs à plusieurs feuilles
- Présentations PowerPoint (.pptx)
- Photos : JPG, PNG, WebP, HEIC, BMP, GIF, SVG, AVIF, etc.
- Vidéos : MP4, MKV, WebM, MOV, etc.
- Audio : MP3, M4A, FLAC, WAV, OGG, Opus
- Markdown, texte brut et code source
- Archives Zip (.zip)
- Modèles 3D (.stl)

Confidentialité dès la conception, et vérifiable

Gander ne demande aucune autorisation. Il ne possède pas l'autorisation INTERNET : il est donc techniquement incapable d'envoyer vos documents où que ce soit. Pas de publicité, pas de traceurs, pas de statistiques d'utilisation, pas de compte.

Inutile de me croire sur parole. Regardez les autorisations de l'application sur cette page : la liste est vide. Lisez la section « Sécurité des données ». Ou lisez le code. Gander est open source sous licence MIT, et tout le code se trouve sur https://github.com/mokshablr/gander

Comment ouvrir vos fichiers

Gander ouvre le fichier que vous lui confiez : via le sélecteur de fichiers du système, via « Ouvrir avec » depuis votre gestionnaire de fichiers ou une autre application, ou depuis un dossier auquel vous lui donnez accès une fois pour toutes. Il n'analyse pas votre téléphone, ne le parcourt pas de lui-même et ne demande jamais l'autorisation d'accès au stockage. C'est un choix de confidentialité, pas une fonction manquante. Les fichiers récents réapparaissent avec leurs miniatures, et les dossiers autorisés restent à portée de doigt.

Conçu pour lire sur un téléphone

- Recherche dans les PDF, Word, Excel, PowerPoint, Markdown, textes et code, avec passage d'un résultat à l'autre
- Sélectionnez et copiez du texte dans un PDF, et faites lire le PDF par un lecteur d'écran
- Ouvrez les PDF protégés en saisissant leur mot de passe
- Mode nuit pour les PDF et les documents Word : le papier devient noir et le texte blanc, les couleurs gardent leur teinte, et les photos restent exactement telles qu'elles ont été imprimées
- Zoom poussé sur les grandes photos grâce au décodage par tuiles, et orientation correcte lue dans les données EXIF
- Partagez le fichier ouvert, enregistrez-en une copie ou ouvrez le dossier où il se trouve
- Design Material 3, mode sombre, affichage bord à bord

Léger : un seul téléchargement pour tous les téléphones

Environ 5 Mo, une seule version qui fonctionne sur tous les processeurs, sans aucune bibliothèque native, sur Android 8.0 et versions ultérieures.

Ses limites, en toute franchise

- Gander est une visionneuse, pas un éditeur
- L'ancien format binaire .ppt n'est pas pris en charge. Les .xls et .doc binaires le sont
- Les présentations PowerPoint complexes s'affichent de façon approximative, et les graphiques des feuilles de calcul n'apparaissent pas
- L'affichage des PDF nécessite Android System WebView 125 ou plus récent, et Gander vous le signale clairement si votre version est plus ancienne
- L'application elle-même est en anglais

Si vous voulez une visionneuse hors ligne de PDF et de documents qui affiche simplement vos fichiers et ne touche à rien d'autre, c'est Gander.
