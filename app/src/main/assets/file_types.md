# File types

### Documents

- PDF `.pdf`
- Word `.docx` `.docm` `.dotx` `.doc` `.dot`
- OpenDocument `.odt` `.ott` `.fodt`
- Rich Text `.rtf`

### Spreadsheets

- Excel `.xlsx` `.xls` `.xlsm` `.xlsb` `.xltx`
- CSV `.csv`
- OpenDocument `.ods`

### Slides

- PowerPoint `.pptx` `.ppsx` `.pptm` `.potx`

### Photos and images

- `.jpg` `.jpeg` `.png` `.heic` `.heif` `.webp` `.gif` `.bmp` `.svg` `.avif` `.ico`

### Video

- `.mp4` `.m4v` `.mov` `.mkv` `.webm` `.3gp` `.3g2` `.avi` `.flv` `.m2ts` `.mts`
- `.ts` when labelled as video

### Audio

- `.mp3` `.m4a` `.aac` `.flac` `.wav` `.ogg` `.oga` `.opus` `.amr`

### Markdown

- `.md` `.markdown`

### Text and code

- Plain text `.txt` `.log`
- Data and settings `.json` `.xml` `.yaml` `.yml` `.toml` `.ini` `.cfg` `.conf` `.properties`
- Code `.kt` `.java` `.py` `.js` `.ts` `.html` `.htm` `.css` `.sh` `.zsh` `.bash` `.c` `.cpp` `.h` `.hpp` `.rs` `.go` `.rb` `.php` `.sql` `.swift` `.dart` `.gradle` `.r` `.tex`
- Subtitles `.srt` `.vtt`
- Playlists `.m3u`
- Download notes `.nfo`
- Verilog and VHDL `.v` `.vh` `.sv` `.svh` `.vhd` `.vhdl`
- Graphviz graphs `.gv` `.dot`

### Books

- EPUB `.epub`, without DRM

### Zips

- `.zip`

### 3D models

- STL `.stl`

### Anything else

Opens as text when it reads as text.
